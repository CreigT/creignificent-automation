# Frontend Scaffold

## Planned Stack
- Next.js 15
- TailwindCSS
- TypeScript
- Supabase Auth
- Vercel Deployment

## Planned Pages
- /
- /dashboard
- /saved-contracts
- /login
- /register

## Planned Features
- Live contract search
- AI explanations
- Saved opportunity tracking
- Deadline alerts
- User dashboard
- Mobile responsive UI

## Initial Setup Commands

npx create-next-app@latest frontend --typescript --tailwind --eslint

cd frontend

npm install @supabase/supabase-js
npm install lucide-react
npm install axios

## Deployment
- Push to GitHub
- Import repo into Vercel
- Add environment variables
- Deploy
