# Creignificent LLC — Official Commercial Cleaning Landing Page

Production-oriented static landing page package for Creignificent LLC commercial cleaning and janitorial marketing.

## Files
- `index.html` — official landing page with embedded CSS/JS and JSON-LD
- `requirement.text` — owner-approved specification
- `llms.txt` — answer-engine citation brief
- `robots.txt` — search and AI crawler policy
- `sitemap.xml` — root sitemap template

## Before public deployment
1. Replace every `https://YOUR-DOMAIN.com/` occurrence with the verified production domain.
2. In the `BUSINESS` object near the bottom of `index.html`, set the verified business phone display value, E.164 phone dial value, and business email.
3. Add a street address only if Creignificent LLC publicly uses that address.
4. Add verified Google Business Profile and social `sameAs` URLs when available.
5. Add a privacy policy URL.
6. Connect the quote form to a production form endpoint when ready; the current page uses a validated mailto workflow after a verified business email is configured.
7. Validate structured data before launch.
8. Deploy the contents of this folder at the production domain root so `/llms.txt`, `/robots.txt`, and `/sitemap.xml` resolve correctly.

## Launch verification
- Confirm one H1 and logical heading structure.
- Confirm all visible FAQ answers match FAQPage JSON-LD.
- Confirm canonical and Open Graph URLs use the production domain.
- Confirm phone CTA works on mobile.
- Confirm quote submission reaches the verified business email.
- Confirm no placeholder domain, phone, email, address, certification, review score, or unsupported claim remains.
- Submit `sitemap.xml` in Google Search Console.

GitHub-ready source package. **Not production-domain ready until the verified domain, phone, email, and privacy-policy details are supplied.**
